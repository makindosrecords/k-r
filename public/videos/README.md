# Video Assets for K&R Photography

Place your compressed background video loops in this directory:
- `/public/videos/hero-background.mp4`
- `/public/videos/hero-background.webm`

## Recommendation for High Performance (95+ Lighthouse Score):
- Resolution: 1080p or 720p
- Frame rate: 24fps or 30fps
- Target File Size: < 5MB
- Encoding: H.264 (MP4) + VP9 (WebM)
- Video attributes used in `<video>` tag: `autoplay muted loop playsinline`
